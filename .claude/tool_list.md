# Python Development Tools Reference

Quick reference of tools to document with their primary purposes.

## Package Management
- **uv** - Fast Python package installer and resolver
- **pip** - Standard Python package installer  
- **poetry** - Dependency management and packaging
- **pipenv** - Virtual environment and package management
- **conda** - Cross-platform package manager

## Code Quality
- **ruff** - Fast Python linter and formatter
- **black** - Code formatter
- **flake8** - Style guide enforcement
- **pylint** - Code analysis tool
- **mypy** - Static type checker
- **bandit** - Security linter

## Testing
- **pytest** - Testing framework
- **unittest** - Built-in testing framework
- **coverage** - Code coverage measurement
- **tox** - Test automation
- **hypothesis** - Property-based testing

## Development Environment
- **virtualenv** - Virtual environment creation
- **pyenv** - Python version management
- **docker** - Containerization platform
- **pre-commit** - Git hooks framework

## Version Control
- **git** - Distributed version control
- **gitflow** - Git branching model
- **commitizen** - Conventional commits

## Documentation
- **sphinx** - Documentation generator
- **mkdocs** - Markdown documentation
- **pdoc** - API documentation

## Build & Distribution
- **setuptools** - Package building
- **wheel** - Binary distribution format
- **twine** - Package uploading to PyPI

## Monitoring & Debugging
- **pdb** - Python debugger
- **logging** - Built-in logging
- **sentry** - Error tracking
- **prometheus** - Metrics collection
