# ドキュメントチェックリスト

ドキュメントのレビュー時にこのチェックリストを使用してください。

## コンテンツ構造

- [ ] はじめに: 対象読者，本資料のゴール，この資料で説明しないことが書かれている
- [ ] 概要: ツールが何をするかの明確な説明
- [ ] インストール: 複数のインストール方法をカバー
- [ ] クイックスタート: ユーザーがすぐに開始できる簡単な例
- [ ] 基本的な使用法: コアコマンドと機能
- [ ] 使用例: コードサンプル付きの実世界での使用ケース
- [ ] ヘルプ: ヘルプの使い方・見方が描かれ散る
- [ ] トラブルシューティング: よくある問題と解決方法
- [ ] リソース: 公式ドキュメント、リポジトリ、コミュニティへのリンク

## 品質チェック

### 正確性

- [ ] バージョン番号が最新である
- [ ] コマンドがドキュメント通りに動作する
- [ ] リンクが有効でアクセス可能である

### 明確性

- [ ] 技術用語が説明されている
- [ ] 例に期待される出力が含まれている
- [ ] ステップバイステップの指示が明確である
- [ ] コードブロックが適切にフォーマットされている

### 完全性

- [ ] インストールが主要プラットフォーム(Ubuntu, MacOS, Windows)をカバーしている
- [ ] 一般的な使用ケースが対応されている
- [ ] 他ツールとの統合がカバーされている
- [ ] エラーメッセージが説明されている

### 使いやすさ

- [ ] 長いドキュメントには目次が提供されている
- [ ] セクション間の相互参照がある
- [ ] 全体を通して一貫したフォーマット
- [ ] コード例がコピー&ペースト可能である

## 日本語対応（該当する場合）

- [ ] 技術用語に日本語説明がある
- [ ] 例が適切なコンテキストを使用している
- [ ] 文化的配慮がされている
- [ ] ディレクトリパスでスラッシュを使用している
